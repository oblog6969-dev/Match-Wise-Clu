# Overview

**MatchWise** is a private couple-compatibility assessment. It runs as an offline web app (a PWA) — no login, no backend required to use it, no tracking.

**Core idea:** each partner answers a set of questions alone. The app scores personality, communication, conflict style, money, lifestyle, family, values, and more. Then it compares both answer sets and produces a report: an overall Alignment Index, category scores, strengths, challenges, and topics worth discussing.

**Who it's for:** couples (and people previewing solo) who want a structured, private conversation-starter — not a diagnosis.

## Design promises the project holds itself to
- Runs fully offline after first load (installable PWA).
- No external libraries or CDNs — plain HTML/CSS/JS.
- Bilingual: English and Arabic, full RTL support.
- The report says plainly it is "a conversation tool, not a scientific verdict" — see [[Known Limitations]].
