# Build MatchWise Lite v1.0

You are a senior full-stack software engineer, UX designer, product designer, psychologist assistant, and AI architect.

Your task is to build a production-quality offline web application called **MatchWise Lite**.

This is NOT a simple personality quiz.

It is a relationship compatibility assessment.

The application must run entirely inside the browser without requiring any backend, database, login, API, or internet connection.

Everything should be contained in a single folder.

# Profiles

Each completed assessment becomes a reusable profile.

The profile should contain

* random profile id
* creation date
* application version
* answers
* calculated personality traits
* calculated values
* assessment confidence

Profiles are exported as encrypted JSON files.

Users never need to retake the assessment unless they want to update their profile.
